# @nuxt-laravelize/events

Framework-neutral synchronous event dispatching with container-resolved listeners. Queue integration is provided separately by `@nuxt-laravelize/events-queue`.

See the complete [English](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.md#events) or [Spanish](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.es.md#events) guide for listeners, subscribers and testing examples.
