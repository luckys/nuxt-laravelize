# @nuxt-laravelize/core

Container, service-provider lifecycle and Nuxt adapters shared by every Nuxt Laravelize feature.

Feature packages install and activate this package transitively. Applications normally do not need to declare it directly.

See the complete [English](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.md#core) or [Spanish](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.es.md#core) guide for container, provider, logging and testing examples.
