# @nuxt-laravelize/mail

Portable mailables with log and Resend-compatible transports. Import Nodemailer adapters from the Node-only `@nuxt-laravelize/mail/node` entry point.

See the complete [English](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.md#mail) or [Spanish](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.es.md#mail) guide for mailables, transports, attachments and tests.
