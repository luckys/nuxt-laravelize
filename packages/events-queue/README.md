# @nuxt-laravelize/events-queue

Optional adapter that serializes marked event listeners into queue jobs without coupling the events and queue packages.

See the complete [English](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.md#queued-event-listeners) or [Spanish](https://github.com/luckys/nuxt-laravelize/blob/development/docs/modules.es.md#listeners-encolados) guide for serializable events and queued listeners.
